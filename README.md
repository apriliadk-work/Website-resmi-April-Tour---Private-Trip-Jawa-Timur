## Deploy ke GitHub Pages

1. Push semua file ke branch `main`
2. Buka **Settings** → **Pages**
3. Source: `Deploy from a branch` → Branch: `main` → folder: `/ (root)`
4. Save — website live dalam beberapa menit!
